# Marketing & Sales Assets

Reproducible marketing assets for the URL Shortener product. Everything in this
directory is generated by the scripts in `marketing/scripts/` and can be
regenerated against any running instance of the app.

## Contents

```
marketing/
├── screenshots/        # 12 PNGs at desktop / tablet / mobile, EN + AR, light + dark
├── videos/
│   └── demo-short.mp4  # ~14 s product walkthrough (anatomy → shorten → pricing → RTL → status)
└── scripts/
    ├── screenshots.ts  # Re-captures the curated screenshot set
    └── demo-video.ts   # Re-records the short walkthrough and transcodes to MP4
```

## Regenerating

Both scripts assume a running server (default `http://localhost:3000`; override
with `PORT` or `BASE_URL`).

```bash
# Start the server in another shell, then:
PORT=3001 npx tsx marketing/scripts/screenshots.ts
PORT=3001 npx tsx marketing/scripts/demo-video.ts
```

Requirements: a system Chrome at `/usr/bin/google-chrome` (the scripts use
Playwright's `channel: 'chrome'`) and `ffmpeg` on `PATH`.

## Notes for the buyer

- The demo video uses anonymous test data only — no real customer URLs.
- All assets are derived from the production build. Re-record after any UI
  change to keep the deck in sync.
- The walkthrough script can be extended for a longer (2–4 min) video by
  appending more `page.goto` / `page.click` steps; see comments inside
  `marketing/scripts/demo-video.ts`.
